Python 示例
本页面演示如何使用 OpenAI 客户端库在 Python 中使用 uncloseai.API 端点。 所有示例均使用相同的 OpenAI 兼容 API 接口，因此可以轻松地在不同的模型和端点之间切换。

可用端点：

Hermes： https://hermes.ai.unturf.com/v1 - 通用对话式人工智能
Qwen 3 Coder： https://qwen.ai.unturf.com/v1 - 专业编码模型
TTS： https://speech.ai.unturf.com/v1 - 文本转语音生成
Python 客户端安装
要安装适用于 Python 的 OpenAI 软件包，请使用 pip ：

pip install openai==2.3.0
非流式示例
非流式模式会等待完整的响应后再返回。这种模式使用起来更简单，但生成过程中不会提供任何中间反馈。

使用 Hermes（通用）
# Python Fizzbuzz Example with Hermes
from openai import OpenAI

client = OpenAI(base_url="https://hermes.ai.unturf.com/v1", api_key="choose-any-value")

MODEL = "adamo1139/Hermes-3-Llama-3.1-8B-FP8-Dynamic"

messages = [{"role": "user", "content": "Give a Python Fizzbuzz solution in one line of code?"}]

response = client.chat.completions.create(
    model=MODEL,
    messages=messages,
    temperature=0.5,
    max_tokens=150
)

print(response.choices[0].message.content)

流式传输示例
流式模式会在生成响应时分块返回，从而提供实时反馈。这非常适合交互式应用程序和较长的响应。

使用 Hermes（通用）
# Streaming response in Python with Hermes
from openai import OpenAI

client = OpenAI(base_url="https://hermes.ai.unturf.com/v1", api_key="choose-any-value")

MODEL = "adamo1139/Hermes-3-Llama-3.1-8B-FP8-Dynamic"

messages = [
    {"role": "user", "content": "Give a Python Fizzbuzz solution in one line of code?"}
]

response = client.chat.completions.create(
    model=MODEL,
    messages=messages,
    temperature=0.5,
    max_tokens=150,
    stream=True,  # Enable streaming
)

for chunk in response:
    if hasattr(chunk.choices[0].delta, "content"):
        print(chunk.choices[0].delta.content, end="")

文本转语音示例
使用 TTS 接口从文本生成语音。音频将保存为 MP3 文件。

# TTS Speech Example in Python
import openai

client = openai.OpenAI(
  api_key = "YOLO",
  base_url = "https://speech.ai.unturf.com/v1",
)

with client.audio.speech.with_streaming_response.create(
  model="tts-1",
  voice="alloy",
  speed=0.9,
  input="I think so therefore, Today is a wonderful day to grow something people love!"
) as response:
  response.stream_to_file("speech.mp3")
