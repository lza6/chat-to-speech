关于我们的网络爬虫
我们的团队使用符合伦理规范的网络爬虫进行开放网络的研究和开发。我们秉持负责任的数据收集原则，尊重网站所有者并遵循行业最佳实践。

用户代理
我们的爬虫程序使用以下用户代理进行身份验证：

uncloseai.com/1.42 (ethical web crawler; +https://uncloseai.com)
这清楚地表明了我们的身份，并提供了返回此页面的链接以获取更多信息。

我们做什么
我们的网络爬虫被我们的人工智能系统用于：

回答问题 - 当用户询问网站或特定信息时，我们的机器人可以抓取并分析网络内容，从而提供准确的答案。
研究与开发 ——我们研究网络信息的结构方式，以改进我们的人工智能模型和工具。
内容聚合 ——我们帮助用户发现和理解跨多个网页的信息
我们的道德规范
我们遵循严格的道德准则，以确保我们是良好的网络公民：

1. Robots.txt 合规性
我们始终尊重 robots.txt 文件。如果您的网站 robots.txt 文件禁止我们的爬虫程序访问，我们将不会访问这些页面。

# Example: Block our crawler from specific paths
User-agent: uncloseai.com
Disallow: /private/
Disallow: /admin/
2. 爬行延迟
我们会遵守 robots.txt 文件中指定的抓取延迟。默认情况下，对同一域名的请求之间间隔 2 秒 ，但我们会遵守您指定的任何延迟：

# Example: Set custom crawl delay
User-agent: uncloseai.com
Crawl-delay: 5
3. 智能缓存
我们默认将获取的内容缓存 7 天 。这意味着：

我们不会就同一内容反复访问您的服务器。
降低基础设施的负载
为用户提供更快的响应速度
4. 智能深度爬行
我们采用基于深度的智能爬虫技术：

深度 0 - 仅首页
深度 1 - 首页及直接链接页面
深度 2 - 必要时可深入两层
我们的爬虫会根据是否找到相关信息自动决定爬取深度，这样我们就不会浪费资源去获取不必要的页面。

5. 查询感知相关性
我们根据页面与用户问题的相关性对其进行评分，并优先考虑：

包含用户查询关键词的页面
简洁易读的 URL 优于动态查询字符串
包含大量独特内容的页面
与主题相符的描述性标题
透明度
我们相信应该公开透明地展示我们的爬虫操作：

清晰的身份识别 ——我们的用户代理能够清晰地识别我们。
联系方式 - 本页提供联系我们的详细信息。
开源方法 ——我们的爬虫遵循公开的最佳实践。
绝不进行隐蔽爬取 ——我们绝不隐藏身份或绕过限制。
如何阻止我们的爬虫
如果您不希望我们的爬虫程序访问您的网站，您可以使用 robots.txt 文件进行阻止：

# Block uncloseai.com crawler entirely
User-agent: uncloseai.com
Disallow: /
或者使用服务器的防火墙/WAF 来阻止我们的用户代理字符串。
