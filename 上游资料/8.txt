uncloseai.js：为任何网站添加机器学习功能

汽车

uncloseai.js
uncloseai.js 是一个单文件 JavaScript 库，可为任何网站添加浮动聊天按钮。只需一个脚本标签，即可为您的页面提供完整的机器学习界面：实时聊天、文本转语音、页面朗读、翻译、文件上传、加密设置，并支持 19 种语言。无需服务器、后端或 API 密钥。

核心技术是反向检索增强生成（反向 RAG） ：客户端不再从服务器获取文档填充提示信息，而是提取实时页面内容并直接注入到对话上下文中。模型始终拥有您正在浏览页面的最新数据，这使得小型模型能够发挥远超其规模的性能。无需向量数据库、嵌入或索引管道。只需将 DOM 中的实时内容直接添加到提示信息中。 阅读白皮书。

适用于静态网站、CDN、GitHub Pages 以及任何提供 HTML 服务的托管平台。所有功能均在客户端针对免费的社区推理端点运行。

安装
在你的 HTML 代码中添加一个 script 标签：

<script src="https://uncloseai.com/uncloseai.js" type="module"></script>
右下角会出现一个浮动的 “取消关闭”按钮。 点击即可打开模态框。

19种语言
整个用户界面（按钮、标签、提示、错误信息、占位符）均已翻译成 19 种语言。模型也会以所选语言进行响应。

阿拉伯语、孟加拉语、简体中文、繁体中文、英语、法语、德语、印地语、印尼语、日语、韩语、马拉地语、葡萄牙语、俄语、西班牙语、斯瓦希里语、泰卢固语、土耳其语、乌尔都语。

主题支持
操作系统偏好设置中的自动暗/亮检测
动态颜色适应宿主页面
可与 PicoCSS 配合使用，或提供其自带的内置样式表
移动响应式布局及媒体查询
消息操作
每条聊天消息（用户和模型）都有操作按钮：

📋 复制原始数据 ：以纯 Markdown 格式复制
📄 复制 HTML ：复制渲染后的 HTML
🔊 语音合成 ：将信息合成为音频
💾 下载 ：保存音频文件
🗑️ 删除 ：从历史记录中移除消息
设置面板
点击弹窗顶部的齿轮图标（⚙️）打开设置。所有设置均加密存储在您的保险库中。

模型选择
从动态发现的模型中进行选择。下拉菜单显示端点和模型名称。系统会通过查询每个已配置端点上的 /v1/models 来自动发现模型。

语音选择
42 种以上语音，按 TTS 模型分类。语音由语音端点动态发现。包含标准、高清和克隆语音选项。

语言
切换用户界面和模型响应语言。更改将立即生效，并应用于所有文本。

自定义 API 端点
将 uncloseai.js 指向您自己的 OpenAI 兼容端点（vLLM、Ollama 或任何兼容的服务器）。配置基本 URI 和 API 密钥。内置模型将与您的自定义端点一起继续可用。

代码执行（非沙箱）
提供您的 unsandbox.com API 密钥即可启用代码执行。启用后，机器学习生成的代码即可在沙盒环境中执行。

配置
通过在加载脚本之前设置 window 变量来自定义行为：

<script>
    // Disable built-in styling to use your own CSS framework
    window.UNCLOSEAI_CUSTOM_STYLING = false;

    // Hide the floating button (use the JS API instead)
    window.UNCLOSEAI_FLOATING_BUTTON = false;

    // Force the UI to a specific language
    window.UNCLOSEAI_LANGUAGE = "es";

    // Add custom instructions to the system prompt
    window.UNCLOSEAI_SYSTEM_PROMPT = "You are a helpful coding assistant.";

    // Replace the default system prompt entirely
    window.UNCLOSEAI_SYSTEM_PROMPT_REPLACE = true;

    // Skip full initialization (floating button only, for preview iframes)
    window.UNCLOSEAI_SKIP_INIT = true;
</script>
<script src="https://uncloseai.com/uncloseai.js" type="module"></script>
配置参考
多变的	类型	默认	描述
未关闭 AI_CUSTOM_STYLING	布尔值	真的	启用内置 CSS。设置为 false 则使用您自己的 CSS 框架（PicoCSS、Tailwind 等）。
取消关闭 AI 浮动按钮	布尔值	真的	显示浮动按钮。设置为 false 可隐藏该按钮，并通过编程方式触发模态框。
未关闭人工智能语言	细绳	无效的	强制用户界面和模型响应使用特定语言。覆盖用户偏好。例如： "en" 、 "es" 、 "ja" 、 "zh" 。
UNCLOSEAI_SYSTEM_PROMPT	细绳	无效的	针对该模型的自定义指令。附加到默认提示符，或者在 SYSTEM_PROMPT_REPLACE 为 true 替换默认提示符。
UNCLOSEAI_SYSTEM_PROMPT_REPLACE	布尔值	错误的	如果为 true ，自定义提示符将完全替换默认系统提示符，而不是附加到提示符上。
UNCLOSEAI_SKIP_INIT	布尔值	错误的	跳过完整初始化。仅创建浮动按钮，跳过模型加载和库初始化。用于预览 iframe。
JavaScript API
所有函数均可在 window.uncloseai 命名空间中使用，并作为 ES 模块导出。

模态控制
// Toggle the chat modal open/closed
await window.uncloseai.toggleUncloseaiEmbeddedModal();

// Open the TTS modal directly
window.uncloseai.openTTSModal();

// Open the translation modal directly
window.uncloseai.openTranslateModal();
聊天
// Send a message and stream the response
for await (const chunk of window.uncloseai.sendMessage("Hello")) {
    process.stdout.write(chunk); // each chunk is a text fragment
}

// Get the currently selected model
const model = window.uncloseai.getSelectedModel();

// Get the endpoint for the current model
const endpoint = window.uncloseai.getSelectedModelEndpoint();
文本转语音
// Speak text with the default voice
await window.uncloseai.speakText("Hello world");

// Speak text from a DOM element
window.uncloseai.handleTTSFromElement(document.querySelector('.content'));
页数阅读
// Extract and read the current page content
await window.uncloseai.readPageWithHermes();

// Extract page content as structured text
const content = window.uncloseai.extractWebpageContent();
翻译
// Trigger smart translate on the page
window.uncloseai.handleSmartTranslate();
保险库
// Check if vault is unlocked
window.uncloseai.UncloseVault.isUnlocked();

// Check if a vault exists for this origin
window.uncloseai.UncloseVault.hasVault();

// Get a setting from the vault
window.uncloseai.UncloseVault.get("selectedModel");

// Lock the vault (clears decrypted data from memory)
window.uncloseai.UncloseVault.lock();
小部件库
不要使用浮动按钮，而是在页面内创建嵌入式界面。

全界面
将包含所有功能的完整聊天界面嵌入到任何容器中：

<div class="uncloseai" data-type="full"></div>
自定义界面
选择要包含的具体功能：

<div class="uncloseai"
     data-type="custom"
     data-features="chat,tts,translate,smart-translate,upload,read">
</div>

tts	文本转语音按钮
翻译	翻译按钮
智能翻译	一键智能翻译下拉菜单
上传	文件上传以进行分析
读	朗读页面按钮
浏览器玩具
不是网站所有者？安装一个浏览器插件 ，即可在您访问的每个页面上显示“取消关闭”按钮。轻量级扩展程序，可将相同的脚本标签注入到每个页面。无需服务器，无需帐户。聊天记录保存在浏览器的本地存储中，并按域名进行限制。

适用于 Chrome、Edge、Firefox、Safari、Brave、Vivaldi 和 Arc。

技术细节
ES6 模块 ：以 type="module" 加载，支持 tree-shakeable 导出
获取 API + ReadableStream ：用于 SSE 流式响应
CryptoJS ：用于保险库的 AES-256 加密（动态加载）
marked.js ：Markdown 渲染
highlight.js ：代码语法高亮显示
CSS 自定义属性 ：主题适配
重复加载保护 ：可以安全地多次包含（浏览器玩具 + 原生）
命名空间隔离 ：所有全局变量都位于 window.uncloseai 之下，以避免覆盖宿主页面函数。
令牌和上下文管理
uncloseai.js 会自动处理 token 预算。它会从每个端点的 /v1/models 响应中读取 max_model_len ，估算输入 token 的数量（英语中每个 token 大约 4 个字符），并预留相应的上下文缓冲区。大型模型（32k+ token）会获得 10% 的缓冲区，小型模型则会获得固定的预留空间。

电池供电设备
uncloseai.js 将所有推理任务卸载到社区 GPU 服务器。电池供电设备（手机、平板电脑、笔记本电脑）无需耗电或在本地运行模型即可获得完整的机器学习功能。无需管理 API 密钥，也无需在客户端保护任何凭据。
